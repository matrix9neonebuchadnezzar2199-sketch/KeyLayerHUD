設定

設定ウィンドウ モック（cyber キット）。レイアウトは Corne 42 相当のダミーです。

接続

VIA Raw HID（Usage Page 0xFF60）経由。VIA/VIAL GUI と同時接続はできません。

VID0x0000
PID0x0000
Usage Page0xFF60
Layer Report0x42

実機到着後、VID/PID を設定に登録してください。

レイアウトプロファイル

物理キー配置の正本。キーマップとは別管理です。

キーHalfRowCol
L0R0C0left00
L0R2C5left25
R0R0C0right00

キーマップ

優先順位: ライブ VIA dump → インポート JSON → 同梱サンプル

サンプル keymap（同梱）keymaps/sample-via.json — 4 レイヤー
使用中
VIA バックアップ JSON.json をドラッグ＆ドロップで読み込み
ライブ dump接続中キーボードから 0x11 / 0x12 で取得

HUD 表示

終了
